# PART 1 — Histopathology

## 1. Surgical Histopathology (biopsies & resections, H&E)
The core service: tissue is processed, sectioned, stained (Haematoxylin & Eosin) and examined
under the microscope. Usually grouped **by organ system / subspecialty**:

| Subspecialty | Typical specimens / tests |
|---|---|
| **Gastrointestinal & hepatobiliary** | Endoscopic GI biopsies, liver biopsy, colon polyp/resection, gallbladder, appendix |
| **Breast** | Core needle biopsy, lumpectomy/mastectomy, sentinel node |
| **Gynaecological (gynae)** | Endometrial biopsy, cervical biopsy/LEEP, ovarian & uterine specimens |
| **Uropathology (GU)** | Prostate core biopsy, TURP chips, kidney/bladder biopsy & resection |
| **Dermatopathology** | Skin punch/shave/excision biopsy, melanocytic lesions |
| **Head & neck / oral** | Oral mucosa, salivary gland, laryngeal biopsy |
| **Thyroid & endocrine** | Thyroidectomy, parathyroid, adrenal |
| **Thoracic / lung** | Lung wedge/core biopsy, pleura, mediastinum |
| **Soft tissue & bone** | Sarcoma/soft-tissue mass biopsy, bone lesion, marrow trephine |
| **Neuropathology (CNS)** | Brain/spinal tumour biopsy & resection |
| **Lymph node / haematolymphoid** | Lymph node biopsy (lymphoma workup) |
| **Gross-only / general** | Products of conception, hernia sac, benign excisions |

> Reporting is standardized to **CAP cancer protocols / synoptic reporting** and the **WHO
> tumour classification** (see references).

> **Cytopathology (FNAC, Pap/cervical, effusion & urine cytology) is OUT OF SCOPE** for
> PATHMOLE — intentionally omitted here.

## 2. Immunohistochemistry (IHC)
Antibody stains on tissue to identify cell type or **predictive/prognostic markers**. Split into:

**Diagnostic / lineage panels** (identify tumour origin): e.g. CK (cytokeratins), CK7/CK20,
TTF-1, CDX2, GATA3, p63, S100/SOX10, CD markers (lymphoma panel: CD3, CD20, CD5, CD10…),
synaptophysin/chromogranin, Ki-67 (proliferation), etc.

**Predictive / prognostic markers** (guide therapy — high value for referral oncology):
| Marker | Used in |
|---|---|
| **ER / PR** | Breast (hormone therapy) |
| **HER2 (IHC)** | Breast, gastric (± reflex to FISH) |
| **PD-L1** | Lung, others (immunotherapy eligibility) |
| **MMR panel (MLH1, MSH2, MSH6, PMS2)** | Colorectal, endometrial (Lynch / immunotherapy) |
| **ALK / ROS1 (IHC)** | Lung |
| **Ki-67** | Prognostic across many tumours |

## 3. Frozen Section / Intraoperative Consultation
Rapid tissue diagnosis **while surgery is in progress** (margins, is-it-malignant, node status).
Referral labs may offer this for partner hospitals.

## 4. Special Stains (Histochemistry)
Non-antibody stains highlighting substances/organisms:
- **PAS / D-PAS** (fungi, glycogen), **GMS** (fungi), **ZN / AFB** (mycobacteria/TB),
  **Gram** (bacteria), **Congo red** (amyloid), **Reticulin**, **Masson trichrome** (fibrosis),
  **Perls' Prussian blue** (iron), **Mucicarmine**, **Alcian blue**.

# PART 2 — Molecular Diagnostics

## 5. Solid-Tumour Mutation Testing / NGS Panels
Detect DNA/RNA alterations that drive tumours and guide targeted therapy.
| Test | Typical use |
|---|---|
| **EGFR mutation** | Lung adenocarcinoma (TKI selection) |
| **KRAS / NRAS** | Colorectal (anti-EGFR resistance), lung, pancreas |
| **BRAF (e.g. V600E)** | Melanoma, colorectal, thyroid, lung |
| **ALK / ROS1 / RET fusions** | Lung |
| **EGFR T790M** | Lung — resistance after 1st/2nd-gen TKI |
| **NGS multi-gene panels** | Comprehensive solid-tumour profiling (preferred over single-gene per CAP-IASLC-AMP) |
| **ctDNA / "liquid biopsy"** (roadmap) | Blood-based mutation detection |

## 6. FISH & Cytogenetics
Fluorescence in-situ hybridization for gene amplification/rearrangement/deletion:
- **HER2 FISH** (breast/gastric), **ALK / ROS1 break-apart** (lung),
  **1p/19q co-deletion** (glioma), **MYC / BCL2 / BCL6** (lymphoma),
  **BCR-ABL1**, **N-MYC** (neuroblastoma), **EWSR1** (Ewing/sarcoma).

## 7. MMR / MSI Status
Microsatellite instability / mismatch-repair deficiency — Lynch screening & immunotherapy:
- **MMR by IHC** (4-antibody panel) · **MSI by PCR** · **MSI by NGS**.

## 8. Haematolymphoid Molecular
Leukaemia/lymphoma markers:
- **BCR-ABL1** (CML/ALL), **JAK2 V617F** (MPN), **FLT3-ITD / NPM1 / CEBPA** (AML),
  **PML-RARA** (APL), **B/T-cell clonality (IgH/TCR rearrangement)**.

## 9. Infectious & Other PCR
- **HPV DNA / genotyping** (cervical), **MTB / TB PCR**, **HCV/HBV viral load**,
  other qualitative/quantitative PCR (menu depends on lab scope).

## 10. Hereditary / Germline Panels (roadmap-dependent)
- **BRCA1 / BRCA2** (breast/ovarian), hereditary cancer NGS panels, pharmacogenomics.
